# Kinetics software scope / 动力学软件边界

`scripts/kinetic_diagnostics.py` accepts only the explicitly supplied label
`synthetic_software_test`. It rejects `physical_approved`; there is no implicit
approval, certificate bypass or physical-results mode.

**[EXECUTED RESULT — software only]** The implementation supplies diagnostics for
an abstract three-state, six-rate, single-site continuous-time Markov network.
It uses the existing `science.site_steady_state` solver. The validation status
below applies exclusively to software invariants, not physical predictions.

**[MODEL INFERENCE — mathematical identity]** A common transition-state shift
multiplies an edge's forward and reverse rates by the same factor
`exp(-delta_G_TS / (kB*T))`. Each forward/reverse ratio and the cycle affinity
are therefore unchanged. A network constructed at equilibrium remains at
equilibrium with zero net cycle flux. An initially driven synthetic network
remains driven: preserving its ratios is not a claim of global equilibrium.

**[EXECUTED RESULT — software tests only]** Nine tests passed on 2026-09-20 using
the bundled Python runtime and the command below. Tests check unequal-energy
Boltzmann equilibrium, equal flux through all three edges, site balance,
preserved forward/reverse ratios, fixed-seed reproducibility, and common-TS
rate-control convergence. The homogeneity relation `sum(X_TS)=1` is an independent
check for a nonzero steady flux. Logarithmic net-flux control is undefined at
equilibrium and the implementation rejects that case rather than reporting
misleading zero coefficients.

The bounded Monte Carlo interface takes explicit half-widths, sample count
(1–10,000) and integer seed. One bounded uniform common energy shift can model
correlated toy uncertainty; independent bounded uniform edge shifts can be
added. These distributions and widths are user assumptions for software tests,
not empirical DFT error estimates. Every draw moves both directions of an edge
together. Quantiles describe only the stated synthetic distribution; they are
not predictive intervals for the target reaction. The rate-only model has no
absolute state/TS energies, so its relative shifts cannot establish physical
activation barriers or assess barrier positivity. Numerical overflow or an
unresolved dynamic range is an error, not a successful physical calculation.

**[WORKING HYPOTHESIS]** A physical network would need both quinazolinone Q and
aryl nitrile B, product identity, balanced chemistry/electron stoichiometry,
proton-source role, site-state definitions, verified energy/rate provenance,
standard states, reversibility, potential/activity dependence and transport
separation. Those are not established by the toy network. No Cu–N–P reaction
network, potential trend, selectivity, absolute current, fitted mechanism or
experimental validation is produced by this module. **WP4 has not been executed.**

```text
python -m unittest discover -s tests -p test_kinetic_diagnostics.py -v
```

No target-reaction data or result files are generated by this command.

# CNS 创新立项章程：离子与质子库存能否共同控制借氢反应的选择性和催化剂休眠？

版本：2026-09-16。性质：**待检验的立项章程，不是机理发现、论文接收评估或已完成的预注册。**

本项目采用 Nature / Science 主刊所重视的重大问题、概念进展、强证据和广泛意义来约束立项。**目前不能认定本题已有 CNS 级新意，更不能认定项目已达到投稿水平。** 最值得继续验证的窄问题是：在明确的 Mn 钳形配合物借氢 N-烷基化体系中，能否找到并测量同一组溶液物种，使离子与可交换质子库存的变化同时解释胺/亚胺分支和可逆休眠，并据此作出无需逐条件再拟合的干预预测与第二配体骨架预测？

现有证据只支持把它列为候选问题。加入数学约束、DFT、AI、超算或更多仪器并不会自动增加概念新意。若结果只是把已知现象放入同一程序，应按复现、方法实施或体系专属机理研究评价。

## 3. 唯一主创新候选及用词边界

**待检验的候选主张 C1：** 在定义清楚的底物、Mn 配体骨架和溶液条件范围内，检验离子配对及可交换质子在若干待鉴定候选物种间的分配，是否共同限制有效金属氢供给和可逆休眠比例；进一步检验同一物种模型能否同时预测胺/亚胺比例、催化速率、休眠积累及恢复轨迹，并在预先锁定的第二骨架上保留预测能力。这些物种和预测能力尚未由本项目建立。

这里的“共同”必须落实到具体物种和共享参数约束。只有两个输出相关、都随加碱变化，不能排除两个互不相关过程同时响应同一扰动。也不预设所有结果必然压缩为一个标量，更不预设所谓“普适阈值”必然存在。

“质子库存”指配体、醇/醇盐、水及其他可交换位点的物料分配与相关活度，不指甲苯中可随意套用的水相 pH。“离子库存”应区分投入 K/Na 总量、溶解部分、离子配对/聚集和可测的结合状态。0.05 equiv tBuOK 不是已知的自由碱活度。温度 383.15 K、甲苯、基准 0.05 equiv 是用户研究条件，不是已复现的文献最优条件。

初始入口采用 P01 的实验对应 Mn-PNP 前体，先恢复可信的化学身份和可比基准。公开 CIF 是固态前体证据，不是热溶液活性物种或自旋态证明。若该骨架不能在可研究条件下同时呈现可区分的选择性变化和可逆休眠，则不要把来自其他配体体系的证据拼成一条机制。可在记录理由后重选实验对象，但原盲测应宣布终止。

## 5. 最小区分证据与预先锁定的预测

先由有资质的实验合作者确认可测量性，再决定具体仪器和条件。这是因果观测设计，不是无人监督的实验操作 SOP。

1. **把产物与催化剂同时纳入时间轴。** 最少需要可校准的底物/醛/亚胺/胺轨迹、催化剂物种或其可验证代理、碱/醇/水相关库存、气相边界与碳/金属衡算。单一终点收率不足以区分共同机制与平行过程。检测不到物种时应报告检测限、响应因子与候选物种可排除范围，不能把缺峰直接当不存在。
2. **把阳离子与其他变化拆开。** 对候选扰动匹配温度、溶剂、有效碱量及可能的相态差异，独立检查有机缩合和亚胺还原分支。离子添加或络合也可能改变溶解/聚集，不能默认只改变一个微观变量。
3. **把可逆休眠与不可逆失活拆开。** 锁定恢复挑战的对照与物料衡算；测试能否由已存在的休眠种回到原催化网络，而不是生成了另一种催化剂。对于原位谱图的物种归属，需要正交证据；仪器数量不是归属正确性的保证。
4. **进行历史挑战和状态匹配挑战。** 不同加料/老化历史但相同名义终点浓度，仅能检验“名义输入是否足够”。若进一步匹配模型声称足够的完整可测状态，未来轨迹仍不一致，就否定该状态闭合假设。开放体系还必须记录气体逸出、体积与温度历史。
5. **最后才锁定第二骨架。** 可由结构、独立化学测量或独立计算给出骨架相关参数；在读取其目标反应测试结果之前冻结生成规则和误差模型。这里要求规则迁移，不要求不同配体的每个微观速率常数相等。利用测试终点或动力学重新标定后，应改称适配。

预注册记录至少包括：目标物种与替代归属、候选网络、允许的参数来源、训练/验证/盲测批次、结构与底物范围、干预方向/幅度/时间尺度预测、原始观测模型、误差相关性、缺失与排除规则、数据版本及代码哈希。将整次实验/批次/骨架留出，禁止把同一条轨迹的相邻时间点随机拆到训练和测试中。

选择性宜事先规定为给定转化率区间的产物比例或完整时间函数；恢复应规定速率/物种随时间的目标量，避免事后挑选最有利时间点。比较采用留出预测误差、预测区间覆盖和预先指定的实际改善量；复杂度惩罚及参数不确定度同时报告。数值容差、独立重复数量与有用改善阈值须在测量重复性先导实验后、盲测前冻结。**本章程没有假装这些尚未测定的阈值已经预注册。**

公平对照至少保留：B0 仅有阳离子相关分支速率的模型；B1 选择性与休眠独立的模型；B2 共享物种模型；B3 使用相同可得观测、同样数据划分的经验回归/状态空间模型。不能给 B2 多种原位输入却只给基线初始投料，再据此宣称机理优越。拟合优度相近时优先较简、可辨识且盲测可靠的解释；允许结论是现有数据无法区分。

## 6. 数学物理与专业计算的角色

物料/电荷守恒、正浓度、共享物种与过渡态自由能的一致性、可逆基元反应的局部详细平衡、开放边界的物质交换和相应热力学核验，是防止模型违反已知物理的门槛。不能给每个条件任意调整正逆速率，再把拟合称为机制。熵产生非负或 ODE 能稳定求解也不证明所选化学网络真实。

可辨识性应同时检查结构层面和实际数据层面；用模拟数据回收参数只能验证方法在假设模型下工作。真实物种证据、可区分干预和盲测仍不可替代。DFT 提供候选结构、势垒及方法敏感性；需要与溶液化学和实验范围相容。是否引入自旋交叉，应由有效竞争路径证据决定，不能为了题目新颖而强行安排 MECP。

## 7. 当前状态和下一步决策

依据本章程起草时的 [Phase 4 状态快照](../data/phase4/PHASE4_STATUS.json)：无私有实验数据、尚无超算账户；早期 local_pilot_001 量化试算 3 次、SCF 收敛 2 次、数值自旋质量通过 1 次，但有效生产级自旋差为 0。后续公开前体 GFN2-xTB 松弛结果另列于 [计算决策计划](COMPUTATION_DECISION_PLAN.md)，不能混为旧模型 DFT 结果。新增已认可 TS、MECP、真实动力学预测仍为 0。软件测试和前体模型极小值不改变这些科学证据边界。

第一关是复现和观测能力：明确实验对应前体、可信反应基准、可测状态和重复性。第二关是同一体系是否确有需共同机制解释的现象。第三关是独立干预能否淘汰分立解释。第四关才是冻结模型与第二骨架预测。任何一关失败，都应降低或放弃相应主张，而不是增加模型自由度、更多仪器或更大的计算任务来遮盖失败。

在真正取得结果前，只可写“我们检验……”，不能写“我们发现……”。即使上述科学关卡通过，也还需要持续查重、完整原始数据、独立复核以及主刊编辑对广泛重要性的判断；不承诺 CNS 接收率或分区。
